
# Functional Requirements

| ID | Requirement | Description |
|---|---|---|
| FR01 | Registration | Users can create accounts. |
| FR02 | Login | Users can securely log in. |
| FR03 | Authentication | System uses JWT authentication. |
| FR04 | Profile | Users can manage profiles. |
| FR05 | Income | Users can add, update, view and delete income. |
| FR06 | Expenses | Users can add, update, view and delete expenses. |
| FR07 | Categories | Users can manage categories. |
| FR08 | Budgets | Users can create and update monthly budgets. |
| FR09 | Budget Monitoring | System compares spending with budgets. |
| FR10 | Transaction History | Users can view previous transactions. |
| FR11 | Dashboard | Displays income, expenses and balance. |
| FR12 | Reports | Generates monthly and category-wise reports. |
| FR13 | Admin | Admin manages users and system categories. |
