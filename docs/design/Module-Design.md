# Expense Tracker & Budget Manager

## System Modules

The project is divided into the following modules:

### 1. User Management
- User registration and login.
- Secure authentication using JWT.
- Manage user profile.

### 2. Category Management
- Add new categories.
- View, update and delete categories.
- Organize income and expenses.

### 3. Expense Management
- Add daily expenses.
- View expense history.
- Update and delete expenses.

### 4. Income Management
- Record income.
- View income history.
- Update and delete income records.

### 5. Budget Management
- Create monthly budgets.
- Set spending limits.
- Monitor budget usage.

### 6. Reports and Dashboard
- Display total income and expenses.
- Show monthly financial summaries.
- Display category-wise spending.
- Compare income and expenses.

### 7. Administration
- Manage registered users.
- Manage system-wide categories.
- View system reports and settings.
